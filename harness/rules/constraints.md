# 제약

- 기본 정책 모드는 드리프트는 경고하고, 치명적 공백은 차단한다.
- 모든 기능 변경은 `harness/specs/`의 기능 명세를 먼저 가져야 한다.
- 아키텍처 또는 횡단 관심사 결정은 `harness/adrs/`의 ADR로 남겨야 한다.
- AI 응답은 사용한 명세, ADR, 규칙을 반드시 인용해야 한다.
- 저장소 상태가 명세나 ADR과 충돌하면 추측하지 말고 에스컬레이션한다.
- MVP는 오프라인 단일 플레이를 유지한다.
- 머지 규칙과 난이도 상승은 결정적이어야 하며 테스트 가능해야 한다.
- 효과음은 앱 자산과 네이티브 셸 오디오 채널로 재생하고, 햅틱은 플랫폼 피드백 API를 사용한다.

## 감지된 스택 요약

- 프로필 팩은 감지되지 않았지만 Flutter 기반 퍼즐 게임 구조를 사용한다.

## 제안 프로필 팩 제약

현재 추가 제안 팩은 없다. 저장소별 제약은 이 문서에 직접 유지한다.
